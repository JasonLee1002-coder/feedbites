# 「許願」還是「敲碗」？幫我想一下

我是 Jason。我們給餐廳用的會員點數產品「常來點」裡，有一個功能要定名字，想聽你的判斷。

## 這個功能在做什麼

客人在手機上告訴餐廳「我想吃什麼」或「希望你們推出什麼」。例如「希望有素食早午餐」「想喝無糖的奶茶」「晚上能不能加一道下酒菜」。

- 客人送出一則，得到少量點數。
- 店長在後台看到所有人的心願匯總，看得出哪個需求最多人要。
- 店長採納之後，提出的客人會收到通知，並拿到大量點數。
- 同一個需求很多人按「我也要」，店長更容易看到。

## 為什麼卡住

中文我們傾向叫「**敲碗**」。台灣網路用語，意思是大家一起敲著碗喊「快推出」，有畫面、年輕、有社群感，也暗示「我也要」的集體動作。

但我們第一家店在高雄駁二，**外國觀光客很多**，韓國、日本、歐美都有。敲碗是台灣才懂的梗，外文沒有對應的詞。

「**許願**」比較普通，但英文 Wish、日文 リクエスト 或 お願い、韓文 소원 都很直接。

## 想請你判斷

1. **中文用「敲碗」還是「許願」？** 考慮台灣客人的感受、店長看得懂、外國客人看翻譯版能不能懂，直接給結論與理由。
2. **可不可以中外文用不同概念？** 例如中文叫「敲碗」，英文叫 Wish 或 Request。這樣會不會讓品牌不一致、或造成客人或店員溝通困難？
